# Sarojini Naidu Poetry Analysis

This project focuses on analyzing the poems of Sarojini Naidu using Natural Language Processing (NLP) and Machine Learning techniques. The system is designed to classify poetic tone, sentiment, themes, and literary patterns from poetic texts.

The project uses TF-IDF vectorization and Logistic Regression as the baseline model for poetic text classification. It later extends toward advanced transformer-based architectures such as LLaMA for deeper literary understanding and poetry generation.

The dataset contains annotated poems with parameters such as:

* tone
* sentiment
* themes
* symbolism
* imagery
* rasa alignment
* musicality

The goal of the project is to combine computational linguistics with literary analysis and Indian aesthetic theory to create an intelligent poetry-analysis framework.
